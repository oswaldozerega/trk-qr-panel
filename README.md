# TRK QR Code Generator · panel

Interfaz del panel privado de TRK QR Code Generator (v1.0.0) para The Roofing Knight. **Este repositorio no contiene datos**:
el panel se muestra dentro de la página "TRK QR Code Generator" del panel de control de Wix de
theroofingknight.com, y todos los datos viajan por esa página hacia el backend de Wix, que verifica
el permiso de administrador en cada operación. Abierto fuera de Wix, el panel no carga nada.

Publicado con GitHub Pages desde la rama `main`.
